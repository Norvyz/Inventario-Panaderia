# Estilo UI Aplicado

Se aplicó un diseño limpio, minimalista y profesional con tonos cálidos (naranja panadero) para reflejar una panadería.

## Paleta
- Primario: `#ff9f40`
- Primario oscuro: `#f28c1f`
- Fondo: `#f5f3ef`
- Tarjeta: `#ffffff`
- Texto: `#1f2937`
- Muted: `#6b7280`
- Éxito: `#16a34a`
- Peligro: `#dc2626`
- Borde: `#e5e7eb`
- Sombra: suave

## Componentes
- Layout con navbar, usuario y logout
- Cards, badges, alertas
- Tablas con hover
- Formularios con focus visible
- Login centrado con branding
- Dashboard con KPIs
- Alertas de stock bajo en Insumos
